# Student-Performance-Analysis
## Description
This project analyzes academic performance data for 121 students across 5 subjects (English, Maths, Science, History, Hindi). Built entirely in Microsoft Excel, it includes pivot-based analysis across behavior, demographics, and subject averages, along with a dynamic student search tool and grade distribution charts.
## Project Objective
To analyze student academic performance data across multiple dimensions i.e, subject-wise, behavioral, and demographic using Microsoft Excel, and to derive meaningful insights that can help identify performance gaps and support data-driven decision making.
